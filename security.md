## 📝 Keeping A Record That Stays Useful

Six weeks later you will not remember why anything is configured the way it is.

**The minimum useful record**

| **Field** | **Example** |
| --- | --- |
| Date | when the change was made |
| What | which value moved |
| From/to | the actual numbers |
| Why | the observation that prompted it |
| Result | better, worse, no change |

**Why "why" matters most**

"Range 12 to 16" is useless on its own. "Range 12 to 16 because targets at 100 m
were not being picked up" tells you whether to revert it when the situation
changes.

**Where to keep it**

A single text file next to the loader. Not a spreadsheet, not a notes app —
somewhere you will actually open when you are already in the folder.

**The review habit**

Once a month, read the last twenty entries. Anything with "no change" as a
result can usually be reverted, and reverting shrinks the configuration back
toward something explainable.

**The handover case**

If you ever need to explain the setup to someone else — or to yourself after a
long break — this file is the only thing that makes that possible. The
configuration itself shows what, never why.
